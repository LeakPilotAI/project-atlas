# Phase 2 evidence-state report/export integration

Decision: scoped offline synthetic implementation accepted; Phase 2 HOLD, Phase 3 blocked, production NO-GO.

The existing `AFI_ACCOUNTABILITY_REPORT_V1`, HTML renderer and `AFI_BROWSER_REPORT_V1` export remain byte-compatible by default. An explicit `--evidence-states` bundle option derives a separate `AFI_EVIDENCE_STATE_REPORT_V2` JSON and scriptless HTML companion. The V2 artifact binds to the V1 report hash and exact serialized bytes, original forecast artifact hash, outcome-history head, source ID, asset, horizon, issue/target clocks, dataset and manifest commitments. It reports source-window status and recorded outcome status separately, with reason and missing-session dates. The V2 export is deterministic and uses the existing exclusive, read-back-verified research publisher. It is not imported by the V1 browser viewer.

Every V2 view is reconstructed from the supplied forecast and outcome histories before rendering. Tampering with a companion state cannot be legitimized by merely changing its hash. Missing, immature, partial, contradictory and unverified windows are excluded from the separate strict diagnostic score. Even a complete synthetic window has `authoritative_scored_n: 0`; neither local receipt bytes nor a complete daily-close grid authenticates historical publication or forecasting skill. The V1 diagnostic remains explicitly synthetic and unchanged.

The current full release blockers persist: independent publication/rights evidence, sufficient held-out calibration and skill, historical PAPER policy/accounting review, native browser acceptance, runtime/storage/provider acceptance and the other 21 release decisions. Historical compatibility policy V1 remains draft and inactive.

Stage 17 extends each V2 case with an explicitly versioned `AFI_EVIDENCE_STATE_CASE_V2_1` detail contract. Its cohort identifies asset/class, horizon, model/version, source, original and outcome dataset commitments, and release-source commitment. Its revision detail reports the latest recorded event, source revision and publication time, input revision, correction count and history length. Diagnostic exclusion is separate from the permanent authoritative exclusion `SYNTHETIC_UNAUTHENTICATED`. The scriptless companion table now displays model version, latest revision event, source revision and diagnostic exclusion. The enclosing V2 schema and all V1 bytes remain unchanged; old immutable companion files are not rewritten.

Multi-entry acceptance uses two issue dates, two horizons, distinct bound release sources and an unbound forecast. Reversing the input order yields identical V2 JSON and cases remain sorted by forecast hash. A corrected outcome remains one forecast case, with its revision history disclosed; substituting the wrong review, duplicating a forecast, or mixing a source with the original forecast is refused before export. Existing dataset tests cover repeated record/revision identity, same-time conflicts and late revision refusal at forecast issue time; maturity tests cover missing interior closes, publication-order contradiction and strict exclusion. Synthetic fixtures cannot prove authentic publication order, independence or calibration. The three historical-receipt Ruff findings (`TRY004` twice, `FURB162`) require semantic adjudication and were left unchanged.

Stage 17 selected regression run: 158 passed, 0 failed/skipped, including retained daily visual exact-byte reconstruction. Final focused run after the last fixture refinement: 6 passed. Targeted Ruff, Python compilation and Git diff check pass. These overlapping counts are not additive.

Stage 18 adds an opt-in V2 case-level `publication_order_status`. A review generated after the outcome step it purports to support, or a correction declared published before an earlier recorded outcome, cannot enter even the synthetic V2 diagnostic score. The case remains visible with `PUBLICATION_ORDER_UNVERIFIED`; V1 output and historical artifact bytes are unchanged. `CONSISTENT_DECLARED_TIMES` is only a local consistency result, never proof of authenticated publication or local receipt.
